## 使用KVM的好处与坏处
### 优点：
  KVM只要能够启动并进行正常的游玩，就几乎不会有任何的被检测导致封禁的可能  
  如果KVM中无法启动游戏，那么也不会导致封禁，只是反作弊发现是虚拟机环境并拦下了游戏启动而已  
  所有操作均在主机中实行，与KVM无关，没有任何的检测手段  
### 缺点：
  KVM需要部署显卡直通与Linux系统，操作较为复杂  
  KVM需要较高的CPU配置以及最好需要核显    
  反正缺点就是很多，一大堆。但是不会被检测出作弊直接一计遮百丑，安全性甚至高于DMA
